  PHASE 1 — REDESIGN COMPLET  ✅  TERMINÉE

Contexte
  L'application avait été migrée de Flutter vers Kotlin natif pour résoudre
  des problèmes de navigation D-pad sur Android TV. Le résultat était
  fonctionnel mais visuellement pauvre. L'objectif était d'atteindre un niveau
  Netflix / Prime Video / Disney+.

Ce qui a été fait

  1. Sidebar collapsible (TvMainScreen.kt)
     - Largeur 72dp (collapsed, icônes seules) ↔ 220dp (expanded, icônes + labels)
     - Animation fluide via animateDpAsState + FastOutSlowInEasing (200ms)
     - Déclenchement : hasFocus sur le Column de la sidebar
     - Logo "P" (collapsed) → "PURPLE" lettré (expanded)
     - Badge trial/premium visible (icône étoile collapsed, bloc complet expanded)
     - FocusRequester sur le premier item nav + LaunchedEffect delay(150ms)
       pour l'initialisation du focus au démarrage

  2. Navigation items avec animation (TvMainScreen.kt)
     - Scale 1.0 → 1.06x au focus (spring DampingRatioMediumBouncy)
     - Label AnimatedVisibility (fadeIn + expandHorizontally / fadeOut + shrinkHorizontally)
     - Bordure TvPurpleGlow au focus, fond TvPurple.copy(0.3f) si sélectionné
     - Settings = dialog (pas un écran), déclenché par l'item index 4

  3. Hero banner Live TV (TvHomeScreen.kt)
     - Hauteur 280dp, fond dégradé horizontal + lueur radiale violette
     - Logo de la chaîne (200×130dp, clip RoundedCornerShape 16dp)
     - Badge rouge "● EN DIRECT", nom de la chaîne (34sp Black), groupe (14sp)
     - Bouton "Regarder maintenant" focusable : fond blanc si focus, TvPurple sinon
     - Dégradé vertical en bas pour fondre vers le contenu

  4. Cartes chaînes (TvHomeScreen.kt)
     - Largeur 180dp, image 120dp de hauteur
     - Scale 1.08x + zIndex 1f + bordure 3dp TvPurpleGlow au focus
     - Fond TvBgCard → TvPurple.copy(0.25f) au focus

  5. Écran Films (TvMoviesScreen.kt)
     - Vue catégories : liste de TvThemeCard (genre + compteur + flèche)
     - Section "Reprendre la lecture" en haut si des items récents existent
     - Vue filtrée : LazyVerticalGrid (GridCells.Adaptive 160dp) avec scale
       animation sur chaque carte film
     - Overlay détail film : cover grand format, métadonnées (année, durée,
       note, genre, synopsis), boutons Lecture / Téléchargement / Fermer
     - Gestion complète du statut de téléchargement (icône dynamique)

  6. Écran Séries (TvSeriesScreen.kt)
     - Même structure que Films (catégories → grille filtrée)
     - Overlay détail série : sidebar cover + infos, panel épisodes
     - Onglets saisons (LazyRow scrollable)
     - Bouton "Télécharger la saison" avec compteur de progression
     - Liste d'épisodes : progression de lecture, statut téléchargement,
       indicateur "déjà vu" (barré + grisé si >= 90% regardé)

  7. Correction des erreurs de compilation
     - Problème : tv-foundation:1.0.0 stable ne contient PAS TvLazyColumn /
       TvLazyRow (supprimés avant la release stable). Le JAR ne contient que
       3 classes : ExperimentalTvFoundationApi, TvImeOptionsKt, TvKeyboardAlignment.
     - Fix : remplacement par LazyColumn / LazyRow de compose.foundation.lazy
     - Alias lazyItems pour éviter le conflit avec lazy.grid.items dans
       TvMoviesScreen et TvSeriesScreen
     - Fix Brush.radialGradient : paramètre centerX inexistant → center = Offset(...)
     - Build APK debug réussi ✅

  Environnement de build
     JAVA_HOME=/home/rigolo/android-studio/jbr (JDK bundlé Android Studio)
     ./gradlew :app-tv:assembleDebug --no-configuration-cache

────────────────────────────────────────────────────────────────────────────────
  NOTES TECHNIQUES IMPORTANTES
────────────────────────────────────────────────────────────────────────────────

  - tv-foundation:1.0.0 stable : NE PAS utiliser TvLazyColumn/TvLazyRow
    (supprimés du JAR stable). Utiliser LazyColumn/LazyRow standard.
    Seules classes disponibles : ExperimentalTvFoundationApi, TvImeOptionsKt.

  - Build : toujours utiliser JAVA_HOME=/home/rigolo/android-studio/jbr
    (le JRE système ne contient pas jlink)

  - Règle de parité (mémoire projet) : toute correction appliquée sur app-tv
    doit également être vérifiée sur app-mobile si applicable.

  - Focus TV : préférer Modifier.focusable() + onKeyEvent(KeyUp + Center/Enter)
    plutôt que clickable() pour la compatibilité D-pad.
